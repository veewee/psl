# PSL PSR-7

PSR-7 / PSR-17 bridge over `Psl\IO`. Provides a conformant `Psr\Http\Message\StreamInterface`
backed by a `Psl\IO` handle (`Psl\Psr\Http\Message\Stream`), a reverse
`Psl\IO\ReadHandleInterface` over a PSR-7 stream (`Psl\Psr\Http\Message\StreamReadHandle`),
and a PSR-17 `StreamFactory`.

See the [main repository](https://github.com/php-standard-library/php-standard-library).
